# CLAUDE.md

## Tech Stack

- Plain HTML, CSS, and JavaScript only.
- No frameworks, no build step. Files open directly in a browser.

## Project Structure

The repository is nearly empty for now. Currently it contains only:

- `README.md` – project readme
- `CLAUDE.md` – this file

Update this section as files and folders are added.

## Key Requirements

1. Every page must be responsive and work on desktop, tablet, and phone.
2. Users can toggle between a light and a dark theme. The default is the light theme.

## Rules for Claude

- Explain technical terms in plain language.
- Ask before making big changes.
- Ask rather than guess when something is unclear.

## Feature Plan

### Site structure

- One long scrolling page (`index.html`), read top to bottom.
- A header with the light/dark theme toggle (light by default).
- One lesson section per slide (3-5 in total), in slide order: heading, text, images.
- A short quiz at the end of each lesson.
- Students move between sections by scrolling. No menu, progress bar, intro, or summary.

### Phases

- **Phase 1 – Course from the slides:** build the page from the user's slides (PDF or PowerPoint) for school and university students who should understand the key ideas. Includes the responsive layout, theme toggle, and per-lesson quizzes. Ask the user for the slides when they are ready to build, and get approval on the quiz questions before finalising.
- **Later phases:** none planned yet. Add them here when decided.
